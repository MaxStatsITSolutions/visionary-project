# VISIONARY

AI home transformation — a digital interior studio. Pick a direction, compare before and
after, and keep a private project for your room.

**Stack:** React · TypeScript · Vite · Material UI · Formik · Redux Toolkit · Supabase
(Postgres, Auth, private Storage). No Next.js, no own backend.

## Quick start

```powershell
npm install
npm run dev
```

Open http://localhost:5173. Without `.env.local` the site runs in demo mode.
